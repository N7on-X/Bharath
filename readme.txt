Sorry Madam G

A lightweight interactive web experience built with HTML, CSS, and JavaScript.

The project presents a personalized apology experience through a sequence of interactive dialogs, animations, and visual effects.

Features
Interactive apology dialogs
Multiple user interaction paths
Animated UI elements
Falling petal effects
Dynamic "I'm Sorry" messages
Interactive response buttons
Randomly moving button interaction
Animated ring presentation
Fully client-side implementation
Technologies
HTML5 — Page structure
CSS3 — Styling and animations
JavaScript — Interactions and dynamic effects

How It Works

The application starts with an apology message and presents the user with different interaction options.

Depending on the selected response, the application dynamically changes the displayed dialog and triggers different animations and effects.

The experience includes:

Initial apology dialog
Forgiveness confirmation
Relationship question
Apology animation sequence
Ring presentation
Interactive visual effects
Visual Effects

The project uses JavaScript and CSS animations to create:

Falling petals
Pulsing text
Floating ring animations
Dynamically generated apology messages
Random button movement
Dynamic popup transitions
Dependencies

No frameworks, packages, or build tools are required.

The project runs entirely in the browser using standard web technologies.

External Assets

The ring animation currently uses an externally hosted image resource.

For improved reliability and long-term maintainability, external assets can be stored locally within the repository.

Browser Support

The project is designed for modern browsers supporting standard HTML5, CSS3, and JavaScript features.
